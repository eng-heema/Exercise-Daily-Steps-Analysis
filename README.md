# Exercise & Daily Steps Analysis

## Overview

A Power BI dashboard that analyzes 30 days of daily physical activity, comparing running and walking and tracking daily step trends.

## Business Questions

- How many steps were recorded in total?
- What is the average number of daily steps?
- Which days are the most active?
- How does activity differ between running and walking?

## Key Insights

| Metric | Result |

| Total steps | 273K |
| Average daily steps | about 9.1K |
| Active days | 30 |
| Running | 56.6% (about 155K steps) |
| Walking | 43.4% (about 119K steps) |

- Running accounts for the larger share of total steps.
- Daily activity varies noticeably from day to day.

## Tools

Power BI, Power Query, DAX, Data Modeling
